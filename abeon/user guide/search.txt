1. COMPONENT OVERVIEW
--------------------------------------------------------------------------------
The main page features a central search component and an experience showcase. 
The search component allows users to choose a destination from recent locations, 
select a travel date from a calendar dropdown, and submit the search to navigate 
to the trip results page. The page also features experience cards that navigate 
directly to the service details page upon selection.

3. TEXTUAL FUNCTIONAL SPECIFICATIONS
--------------------------------------------------------------------------------

A. Destination Selection:
   - Clicking on the "Where to?" input field opens the Recent Searches dropdown modal.
   - The dropdown displays five quick-select destinations (Shimla, Chandigarh, Japan, Dubai, Jaipur).
   - Selecting any destination automatically fills the "whereInput" field with the chosen city name and dismisses the dropdown.
   - A "Clear" action button inside the dropdown header empties the stored recent search entries.

B. Exploration Date Selection:
   - Clicking on the "When will you explore?" input field toggles the Datepicker calendar dropdown modal.
   - The calendar displays month controls and a 7-column day grid (Sunday through Saturday).
   - Selecting a date highlights that day and populates the "whenInput" field with the formatted date value (e.g., "Oct 21").
   - Outside clicks dismiss open dropdown panels to maintain a clean interface.

C. Navigation to Trip Page:
   - Activating the search action button (`.search-btn`) initiates navigation.
   - The user is transitioned directly from the search component to the trip results page (`/trip`) with the selected destination and date context applied.
   - In the trip page, clicking on the "Abeon" header title directly returns the user to the search main page (`/`).
   - The trip page header features text-only "Trips" (history) and "Chat" (Guide Messenger) buttons at the right.

D. Navigation to Service Details Page & Booking Lifecycle:
   - Each card rendered inside the experiences grid acts as a direct link target (`/service-details`).
   - Clicking on any part of the card tile (image wrapper, title, rating, or price block) redirects the user directly to the service details page (`/service-details`) showcasing the full experience itinerary, host information, and reservation options.
   - On the service details page, a top-left back button (`.btn-back`) allows immediate navigation back to the trip results page.
   - Top-right action buttons provide access to "Trips" (text-only pill with active count) and "Chat" (guide conversations).
   - If an experience is already booked, the reservation button changes to "Booked" and will not open the booking modal until the active booking is cancelled via the cancellation action.

E. Back Navigation on Trips & Chat Pages:
   - Both the Trips page and Chat page include a dedicated top-left back button allowing users to return effortlessly to the previous page.
